# Runtime dependencies.
#
# Face recognition uses InsightFace (buffalo_l: SCRFD detector + ArcFace
# w600k_r50 embeddings) rather than the spec's originally-chosen
# face_recognition/dlib. That choice was measured, not assumed — see
# README "Face embedding" for the numbers. dlib is also a source build
# needing a C++ toolchain, which InsightFace's ONNX wheels avoid; that
# matters for anyone installing their own copy of this app.
#
# First run downloads ~300MB of models into ~/.insightface/models/.
#
# python-docx is the one dependency for §4.7 export (.docx format) — a
# real OOXML writer isn't reasonable to hand-roll the way this project's
# other API integrations avoid a dependency by using stdlib urllib
# instead (see google_auth.py/picker_client.py/geocoding.py/llm.py).
#
# Install:
#   python3.11 -m venv .venv
#   .venv/bin/python -m pip install -r requirements.txt
